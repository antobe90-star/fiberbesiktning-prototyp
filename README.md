# Fiberbesiktning – mobilprototyp

Fristående HTML-prototyp för fiberbesiktning, med exempeldata. Öppna den i Safari på iPhone:

https://antobe90-star.github.io/fiberbesiktning-prototyp/

`index.html` i roten är hela appen. Inget byggs eller installeras.

Sidan blir nåbar först när repot är publikt och GitHub Pages är påslagen: Settings → Pages → Source: GitHub Actions. Kör sedan om workflowet Publicera GitHub Pages.
